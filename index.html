Click a row to set that step's note, click it again for a rest. The bottom rows add accent, slide and octave. The text box shows the letters your notes spell.

Set in Atkinson Hyperlegible, the typeface designed by the Braille Institute. With the Opium kit, saved MIDI uses the rack's own pads, so it plays OPIUM DRUMS in Ableton as is. The Synth kit uses General MIDI drum notes. Bassline MIDI writes accents as louder notes and slides as overlapping notes, so a mono synth with glide slides like a 303.

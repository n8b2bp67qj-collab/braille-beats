# Braille Beats

Type a sentence or paste braille and hear it as a groove. Two pages, one clock.

## Drums
Every raised dot is a hit.

- **Cell = 2 steps:** left column of the cell plays on one 16th, right column on the next. Rows are sounds. Eight cells = one bar.
- **Cell = 1 step:** the whole cell hits at once; each dot number is its own sound.
- Kits: **Opium** (samples from the OPIUM DRUMS rack, 6 to start, 16 to pick from) and **Synth**. Randomize sounds, save your own kits.

## Bassline
Every cell is a 303-style note, locked to a scale.

- Left column (dots 1·2·3, worth 1·2·4) picks scale degree 1–7. No left dot = rest.
- Right column: dot 4 accent, dot 5 slide, dot 6 octave up. Dot 7 (8-dot braille) octave down.
- Key, scale, octave, saw/square, cutoff, resonance, env mod, decay.

## Both
Shared tempo and swing, drums and bassline play together in sync, a volume fader for each, click the grids to edit (the text box spells the letters back), MIDI export for each part.

One static page plus `sounds/`, no build step, no tracking.

# Braille Beats

Type a sentence or paste braille and hear it as a drum pattern. Every raised dot is a hit.

- **Cell = 2 steps:** left column of the cell plays on one 16th, right column on the next. Rows are sounds (hat / snare / kick, plus rim for 8-dot braille). Eight cells = one bar.
- **Cell = 1 step:** the whole cell hits at once; each dot number is its own sound.
- Tempo, MPC-style swing, editable steps (the braille rewrites itself), MIDI export with General MIDI drum notes (kick = C1 / 36).

One static file, no build step, no tracking. Open `index.html` or host the folder anywhere.
